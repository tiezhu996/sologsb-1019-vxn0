# 访谈文本主题编码工具

`sologsb-1019` 是一个面向质性研究者的本地优先主题编码工作台，使用 SolidJS、TypeScript 和 SUID 从零构建。

## 功能

- 导入带时间码或普通段落形式的访谈转写，自动切分片段。
- 创建任意层级主题树，维护操作定义、备忘录和典型示例。
- 为每个片段分别记录两位编码者的主题判断，并高亮分歧。
- 批量选择片段后重新编码，支持主题合并和按片段拆分。
- 从主题引用快速回到原文，并保留主题级与片段级研究记录。
- 完整撤销重做、操作审计、JSON 完整备份和 CSV 编码结果导出。
- J/K、数字键、Alt+A/Alt+B、搜索与通用撤销快捷键。
- 使用 IndexedDB 和 localStorage 双写保存；改动先记为带基础修订的待提交记录，刷新、断网、浏览器中途关闭后都能恢复重试。
- 使用 BroadcastChannel 监测其他标签页修订，发生并发写入时先收敛到对方版本、逐条保留本页提交，不会静默覆盖。

## 技术栈

- SolidJS 1.9
- TypeScript 5.9
- SUID Material `@suid/material`
- Vite 7
- IndexedDB / localStorage / BroadcastChannel

## 开发

```bash
npm install
npm run dev
```

开发服务器使用 Vite 默认端口，不在源码中硬编码宿主端口。

## 生产构建

```bash
npm run build
npm run preview
```

生产文件输出到 `dist/`。

## Docker

```bash
docker build -t sologsb-1019 .
docker run --rm -p 10019:80 sologsb-1019
```

容器内由 nginx 监听 `80`，宿主端口 `10019` 仅由根项目端口表或部署命令映射。

## 数据说明

数据保存在浏览器本机，不会发送到远端。每次编码改动都会先作为一条**带基础修订的待提交记录**写入 IndexedDB（并镜像到 localStorage），随后在同一个数据库事务里把记录应用到最终快照、推进修订并删除记录：

- 浏览器在中途关闭时，只会留下「待提交记录 + 旧快照」，重开后按记录重放，主题树、片段判断、审计和冲突标记始终一起推进，不会互相对不上。
- 写入失败不会丢失改动：记录保留并按指数退避自动重试，也可在界面上手动重试；只有快照与记录删除在同一事务成功后才清除记录。
- 多个标签页并发时，后写入者通过修订与末端提交双重校验识别分叉，**不会覆盖**先写入者的内容：界面先收敛到其他标签页版本，本页未完成提交逐条保留，由研究者选择「重放到新版本」或「放弃」。
- 重放时若引用的主题、片段或转写已被对方删除，会生成冲突标记（界面与导出均可见），复核后可标记解决。
- JSON 导出包含 `finalRevision`（最终修订）、`pendingCommits`（全部未完成提交，含分叉原因、尝试次数与写入错误）和 `unresolvedConflicts`（未复核的冲突标记）。
